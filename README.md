# Heart-Disease-Predictor

## A Logistic Regression model that predicts heart disease in a patient by using the UCI Heart Disease dataset. The dataset consists of clinical and personal records, such as their age, sex, chest pain, cholesterol, resting blood pressure, and more.

## Model: Logistic Regression

## Dataset: UCI Heart Disease Dataset

## Preprocessing

### Handled missing values and outliers
### Normalized continuous features
### One-hot encoded categorical variables

## Evaluation: Hist Gradient Boosting Classifier

### AUC: 0.8812232415902141
### Sensitivity: 0.7706422018348624
### Specificity: 0.8533333333333334
### Accuracy: 0.8913043478260869
### False Negative Rate: 0.22935779816513757
### False Positive Rate: 0.1466666666666666

## Objective:

### To develop an interpretable and efficient baseline model that can assist in early identification of individuals at risk for heart disease, supporting medical decision-making
